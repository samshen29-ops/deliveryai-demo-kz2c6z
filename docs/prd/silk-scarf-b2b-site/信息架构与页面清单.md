# 信息架构与页面清单

> 配套文档：《PRD.md》。本文定义站点结构、每页的模块顺序、内容要求与 SEO 要素，供设计与前端直接落地。

## 1. 站点地图


**导航原则**
- 一级导航 ≤ 6 项：Collection / Customization / Factory / Journal / About / Contact。
- 任意页面到询盘表单 ≤ 2 次点击。
- 移动端抽屉菜单，底部固定「Get a Quote」按钮（不遮挡表单提交区）。

## 2. 页面模块与内容要求

### 2.1 Home

| 顺序 | 模块 | 内容要求 | CTA |
|---|---|---|---|
| 1 | Hero | 当季主视觉（≥2400px 宽）、一句价值主张（≤12 词）、副标题点明「真丝 · 定制 · 小单可做」 | Explore Collection / Get a Quote |
| 2 | 能力四宫格 | 真丝等级（6A/9A）、手工卷边、MOQ、认证 | — |
| 3 | 精选系列 | 6–8 款，含款号、材质、尺寸、MOQ | View All |
| 4 | 定制流程 | 5 步图示 + 周期 | Start Custom Project |
| 5 | 工厂与认证 | 车间图 + 认证 logo + 产能数字 | Visit Factory |
| 6 | 案例/评价 | 2–3 个案例卡 | Read Case |
| 7 | 询盘引导 | 简短表单入口或「Talk to Our Team」 | Get a Quote |

### 2.2 Collection（列表）

- 顶部：标题 + 一句说明（可筛选的维度提示）。
- 筛选栏：材质 / 工艺 / 尺寸 / 季节 / 场合（桌面左侧吸顶，移动端底部抽屉）。
- 排序：Featured / Newest。
- 卡片字段：主图、次图（hover）、款号、名称、材质、尺寸、MOQ、价格区间（或 Contact for price）。
- 分页或「Load more」（首屏 ≤ 24 款）。
- 空态：提示 + 清除筛选 + 提交定制需求。

### 2.3 Product Detail

| 顺序 | 模块 | 内容要求 |
|---|---|---|
| 1 | 图集 | ≥6 张：整幅、面料微距、卷边细节、色卡、场景、包装；支持缩放 |
| 2 | 标题区 | 款号、名称、一句话卖点、MOQ、交期 |
| 3 | 规格表 | 成分、克重（g/m²）、尺寸、工艺、卷边方式、包装方式 |
| 4 | 阶梯价 | 4 档区间 + 报价口径说明（FOB / 最终以报价单为准） |
| 5 | 定制选项 | 换色（附色卡）、改尺寸、加 logo、换包装、洗标/吊牌 |
| 6 | CTA 组 | Get a Quote（主）/ Request Sample（次）/ WhatsApp |
| 7 | 信任条 | 认证图标 + 质检标准 + 出口国家数 |
| 8 | 相关推荐 | 同系列 4 款 |
| 9 | FAQ 摘要 | 交期、打样、付款方式 3 条 |

### 2.4 Customization

- 5 步流程：需求沟通（1–2 天）→ 设计/打样（7–10 天）→ 样品确认（3–5 天）→ 大货生产（25–35 天）→ 质检出货（3–5 天）。
- 定制维度矩阵：花型、配色、尺寸、卷边、洗标、吊牌、礼盒、条码。
- 规则说明：MOQ、打样费、版权与花型归属、文件格式要求（AI/PDF/300dpi）。
- CTA：Start Your Custom Project。

### 2.5 Factory / Certifications

- 车间实景（印花线、卷边工位、质检台）、设备清单、月产能、员工数、出口国别。
- 认证墙：OEKO-TEX Standard 100、BSCI、Sedex、ISO 9001（含证书图与有效期）。
- 质检：AQL 2.5 抽检说明、验货配合（第三方验货支持）。
- 数据口径与更新时间必须标注。

### 2.6 Quote / Sample

- 左：表单；右：信任侧栏（响应时效、认证、服务过的市场）。
- 样品页额外展示样品政策：样品费、运费承担、下单抵扣规则。
- 提交成功页：询盘编号、24 小时回复承诺、推荐 3 款相关产品、WhatsApp 直达。

### 2.7 Journal（P1）

- 分类：Fabric Knowledge / Trends / Styling / Custom Guide。
- 文章页：目录、正文、产品卡片、相关文章、订阅入口。
- 每篇 ≥800 词，含 1 张主图与 ≥2 张内文图。

### 2.8 FAQ

- 分组：Order & MOQ / Sampling / Production & Lead Time / Payment & Shipping / Customization / After-sales。
- 每组 ≥3 条，答案 ≤120 词，首屏可折叠展开。

### 2.9 Legal

- Privacy Policy、Terms of Service、Cookie Policy、Export Compliance、Copyright & Pattern Ownership。
- 含版本号与生效日期。

## 3. 产品数据模型（内容配置字段）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| ref | string | 是 | 款号，`SC-XXXX`，全站唯一，用于 URL 与询盘带入 |
| name | string | 是 | 英文品名 |
| series | enum | 是 | silk-twill / digital-print / jacquard / wool-blend |
| material | string | 是 | 如 100% Mulberry Silk 16姆米 |
| weight_gsm | number | 是 | 克重 |
| size_cm | string | 是 | 如 90×90 |
| craft | string[] | 是 | 数码印花 / 提花 / 丝网印刷 |
| hem | enum | 是 | hand-rolled / machine-stitched |
| moq | number | 是 | 最小起订量（条） |
| price_tiers | array | 是 | `[{min,max,price_from,price_to}]`，可为空表示 Contact for price |
| lead_time_days | string | 是 | 如 25–35 |
| colors | array | 否 | 色卡（名称 + 色值 + 图） |
| images | array | 是 | ≥6 张，含 alt 文案 |
| packaging | string | 否 | 包装说明 |
| customization | string[] | 否 | 可定制项 |
| status | enum | 是 | draft / published / archived |

## 4. 视觉与体验原则

1. **高级感优先于促销感**：大留白、单列大图、低饱和中性底色（米白 / 燕麦 / 墨黑），主色跟随当季色卡，不使用大红大黄促销色块。
2. **面料可感知**：产品图必须有微距细节与卷边特写，图片质量是本站第一转化要素。
3. **信息密度克制**：每屏只讲一件事；规格用表格，不用长段落。
4. **移动优先**：海外买家 60%+ 来自手机；所有关键 CTA 在拇指热区。
5. **不打断**：不做全屏弹窗、不做自动播放视频带声、不做强制注册。

## 5. 国际化与 SEO

| 项目 | 规则 |
|---|---|
| 默认语言 | en（`/en`），根路径 301 到 `/en` |
| 语言集 | P0：en；P1：es、fr、ar（RTL） |
| URL 结构 | `/{lang}/...`，语言前缀固定 |
| hreflang | 每页输出全部语言版本 + x-default |
| 结构化数据 | Organization（全站）、Product（详情）、BreadcrumbList（层级）、Article（博客）、FAQPage（FAQ） |
| 页面元信息 | title ≤ 60 字符，description 120–155 字符，含核心词 |
| 目标关键词 | silk scarf manufacturer / custom silk scarf wholesale / hand rolled silk scarf supplier / private label silk scarves |
| 图片 SEO | 文件名语义化、alt 含材质与场景、压缩后 ≤200KB |
