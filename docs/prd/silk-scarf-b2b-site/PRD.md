# 产品 Spec：丝巾外贸 B2B 官网（询盘驱动）

> **一句话概述**：为丝巾制造/贸易企业搭建面向海外买家的英文 B2B 独立站，使品牌买手与批发商能够自助完成「选款 → 评估定制能力 → 发起询盘 / 申请样品」，同时用工厂实力与认证建立信任，替代当前依赖 B2B 平台店铺与邮件报价的获客方式。

---

## 1. 背景与目标

### 1.1 背景

| 维度 | 现状 |
|---|---|
| 获客渠道 | Alibaba / Made-in-China 店铺、展会名片、老客转介绍；无自有独立站或仅有静态介绍页 |
| 买家决策 | 买家需反复邮件确认材质等级、工艺、MOQ、交期，平均 5–8 轮往返才能报价 |
| 内容资产 | 产品图、色卡、认证资料散落在网盘与销售个人电脑，无法复用 |
| 市场覆盖 | 仅英文/中文，中东与欧洲买家沟通成本高 |

**核心问题**

1. **平台依赖**：平台流量成本逐年上涨，同质化比价严重，询盘被同行截流，无法沉淀自有域名与内容资产。
2. **能力不可见**：买家无法从页面上判断工厂的真实能力——桑蚕丝等级（6A/9A）、手工卷边（hand-rolled）、数码印花 vs 提花、真实 MOQ 与打样周期。
3. **询盘质量低**：现有询盘缺少目标数量、用途、目标市场、定制意向，销售需重复追问，转化链路被拉长。
4. **信任缺口**：无认证（OEKO-TEX / BSCI / Sedex）、无验厂报告、无产能与出口国别展示，买家不敢下大货。
5. **多语言缺失**：中东（阿语，RTL）、欧洲（西/法）买家流失。

**触发来源**：业务增长目标、平台依赖风险、品牌化与内容沉淀诉求。

### 1.2 目标

| 目标 | 衡量方式 | 目标值 / 判断标准 |
|---|---|---|
| 建立可自主获客的英文官网 | 上线并被搜索引擎收录 | 核心页面 100% 收录，sitemap 提交 Search Console |
| 提升询盘质量 | 询盘必填完整率（含目标数量与用途） | ≥ 85% 的询盘包含目标数量 + 定制意向 |
| 缩短买家决策路径 | 产品详情页 → 询盘提交转化率 | 上线 3 个月内 ≥ 2.5% |
| 建立信任背书 | 关键页面认证/验厂/产能信息覆盖 | 首页、关于、产品详情 100% 可见认证标识 |
| 支撑多市场扩展 | 多语言 / 多币种 | P0 英文（USD）；P1 增加 ES / FR / AR（RTL） |
| 降低销售重复沟通 | 首轮询盘信息完整度 | 销售首封回复即可报价的比例 ≥ 60% |

### 1.3 不做什么（非目标）

- **不做在线支付与实时库存/购物车结算**：B2B 定制订单价格随数量、工艺、材质浮动，MVP 以询盘成交；在线小单（P2）再评估。
- **不做买家账号体系与订单跟踪**：不引入登录、订单中心、历史订单查询。
- **不做供应商入驻 / 多商家 marketplace**：本站仅承载单一卖家（自有工厂或稳定供应链）。
- **不做 3D / AR 试戴、虚拟搭配**。
- **不改动 main 分支现有门店 Demo 代码**：新站在独立的站点目录与 `waimao` 分支上建设。
- **不做在线实时客服系统自研**：仅接入 WhatsApp / 邮件 / 第三方在线客服脚本。

## 2. 用户与场景

| 用户 / 角色 | 使用场景 | 当前痛点 | 期望结果 |
|---|---|---|---|
| 海外品牌买手（Brand Buyer） | 为下一季女装配饰选款，需要看面料细节、色卡与交期 | 图片不清晰、无成分与工艺说明、不知道能否小批量 | 在 3 分钟内判断是否值得联系，并一键发起询盘 |
| 批发 / 分销商（Wholesaler） | 按价格带与 MOQ 找可长期供货的款 | 价格不透明、MOQ 不明、无法比较阶梯价 | 看到阶梯价区间与 MOQ，直接提交目标数量 |
| 精品店主（Boutique Owner） | 小批量采购 50–200 条，做店铺差异化 | 工厂嫌量小不回复；平台店铺起订量高 | 明确的小单政策与样品政策，快速拿到样品 |
| 定制客户（OEM/ODM） | 用自有品牌 logo、自有花型做定制 | 不了解打样流程、周期、费用与版权归属 | 清楚看到 5 步定制流程、打样周期与费用规则 |
| 站内运营（内部） | 上新、改价、维护案例与博客 | 依赖开发改代码，上新周期长 | 通过结构化内容配置上新，不改代码 |
| 销售跟单（内部） | 接收并跟进询盘 | 询盘信息不全、散落在邮箱 | 询盘统一进 CRM，字段完整、可分配跟进 |

## 3. 功能需求

### REQ-001：首页品牌与能力概览（P0）

- **用户价值**：10 秒内让买家判断「这是一家能做定制的真丝工厂，而不是搬货贸易商」。
- **需求描述**：首页自上而下为 Hero（当季主视觉 + 一句价值主张 + 双 CTA「Explore Collection / Get a Quote」）→ 核心能力四宫格（真丝等级 / 手工卷边 / MOQ 与交期 / 认证）→ 精选系列（6–8 款）→ 定制流程 5 步 → 工厂与认证 → 客户案例 → 底部询盘引导。
- **验收标准**：
  - [ ] 首屏 1 屏内可见价值主张、主 CTA 与至少 1 个信任元素（认证或产能数字）。
  - [ ] 首屏 LCP ≤ 2.5s（4G 移动端），无布局跳动（CLS < 0.1）。
  - [ ] 所有 CTA 在移动端可单手触达，点击后进入对应询盘/产品页。

### REQ-002：产品目录与多维筛选（P0）

- **用户价值**：买家按自己的采购维度（材质/工艺/尺寸/季节）快速缩小到 5–10 款，而不是翻 200 张图。
- **需求描述**：目录页支持按 **材质**（100% 桑蚕丝 6A/9A、真丝斜纹、羊毛混纺、棉麻、人造丝）、**工艺**（数码印花、提花、丝网印刷、手工卷边）、**尺寸**（53×53、65×65、90×90、110×110、180×65 cm）、**季节**、**场合** 筛选；支持排序（新品/主推）；卡片展示主图、款号、材质、尺寸、MOQ、起订价区间。
- **验收标准**：
  - [ ] 筛选条件可组合，结果数量实时更新，URL 承载筛选状态（可分享、可回退）。
  - [ ] 无结果时展示空态与「清除筛选 / 提交定制需求」两个出口。
  - [ ] 列表首屏图片懒加载，滚动 60fps 无明显卡顿。

### REQ-003：产品详情与规格 / 阶梯价（P0）

- **用户价值**：一页回答「是什么、能不能做、多少钱、多久到」。
- **需求描述**：图集（≥6 张：整幅、微距面料、卷边细节、色卡、场景图、包装）→ 款号与名称 → 规格表（成分、克重、尺寸、工艺、卷边方式、包装）→ 阶梯价（50–99 / 100–299 / 300–999 / 1000+ pcs，显示区间而非精确单价）→ MOQ 与交期 → 定制选项（换色/改尺寸/加 logo/换包装）→ 双 CTA（Get a Quote / Request Sample）→ 相关推荐。
- **验收标准**：
  - [ ] 规格表字段完整率 100%（成分、克重、尺寸、工艺、MOQ、交期缺一不可）。
  - [ ] 阶梯价随数量档位正确切换，且明确标注「FOB / EXW 报价口径，最终以正式报价单为准」。
  - [ ] 从任意产品卡片进入详情页 ≤ 2 次点击。

### REQ-004：询盘（RFQ）表单（P0）

- **用户价值**：让买家在 90 秒内提交一条销售可直接报价的询盘。
- **需求描述**：表单字段见 4.2；支持从产品详情页带入款号与名称；支持上传参考图（≤3 个文件，单文件 ≤10MB，jpg/png/pdf）；提交后展示成功页并承诺 24 小时内回复（工作日）。
- **验收标准**：
  - [ ] 必填项校验在失焦时即时提示，不阻断输入。
  - [ ] 提交成功后生成询盘编号，页面展示编号与「24 小时内回复」承诺。
  - [ ] 提交失败时保留全部已填内容，展示可重试提示。
  - [ ] 同一 IP 10 分钟内超过 5 次提交被限流，并展示友好提示。
  - [ ] 询盘在 1 分钟内到达销售邮箱与 CRM（或至少邮件）。

### REQ-005：样品申请（P0）

- **用户价值**：B2B 成交的关键动作是「先拿样」，需与询盘区分开，独立承接。
- **需求描述**：可从产品详情页或独立入口发起；字段含收件国家/城市、收件人、电话、期望样品数量（1–3 条/款）、是否接受样品费与运费到付；页面明确样品政策（样品费金额、运费承担方、下单后是否抵扣）。
- **验收标准**：
  - [ ] 样品政策在表单提交前可见，无需跳转。
  - [ ] 提交后销售可在后台按「样品」类型筛选。
  - [ ] 收件信息缺项时阻止提交并高亮缺失字段。

### REQ-006：定制服务（OEM/ODM）（P0）

- **用户价值**：把「能做定制」从口头承诺变成可视流程，降低买家决策不确定性。
- **需求描述**：5 步流程（需求沟通 → 设计/打样 → 样品确认 → 大货生产 → 质检出货），每步标注周期与交付物；明确 MOQ、打样费、版权与花型归属、可提供的定制维度（花型、配色、尺寸、卷边、洗标、吊牌、礼盒）。
- **验收标准**：
  - [ ] 5 步流程含每步周期与买家需提供的材料。
  - [ ] 明确写清打样周期与大货周期区间。
  - [ ] 页面含「Start Your Custom Project」CTA，进入带定制上下文的询盘表单。

### REQ-007：工厂与认证（P0）

- **用户价值**：解决「是不是真工厂」的信任问题，是外贸站转化的前置条件。
- **需求描述**：工厂实景（车间、印花线、卷边工位、质检）、产能数字（月产能、员工数、出口国别数）、认证墙（OEKO-TEX Standard 100 / BSCI / Sedex / ISO 9001，可点击查看证书图）、验厂报告摘要、质量承诺（AQL 抽检标准）。
- **验收标准**：
  - [ ] 认证项均可点开查看证书图片，含有效期。
  - [ ] 产能与出口数据标注统计口径与更新时间。
  - [ ] 证书缺失时展示「Pending」占位，不得伪造。

### REQ-008：全局联系与即时沟通（P0）

- **用户价值**：买家习惯用 WhatsApp 直接问，缺入口即流失。
- **需求描述**：右下角常驻 WhatsApp / Email 入口（移动端不遮挡主 CTA）；页脚展示公司地址、邮箱、电话、工作时间（含时区）、社交账号。
- **验收标准**：
  - [ ] 移动端浮动入口不遮挡底部主按钮与表单提交按钮。
  - [ ] 邮箱为域名邮箱，非 gmail/qq 等免费邮箱。
  - [ ] 工作时间标注 UTC 偏移。

### REQ-009：多语言与多币种（P1）

- **用户价值**：覆盖中东与欧洲买家，降低语言门槛。
- **需求描述**：P1 增加西班牙语、法语、阿拉伯语（RTL 布局镜像）；币种 USD / EUR 展示切换，汇率按固定周期更新并标注「参考汇率」。
- **验收标准**：
  - [ ] 阿语页面 RTL 布局正确，图标与箭头方向镜像。
  - [ ] 语言切换保留当前页面路径，且有 hreflang 标注。
  - [ ] 币种切换仅影响展示，不影响询盘提交的报价口径说明。

### REQ-010：内容与趋势博客（SEO）（P1）

- **用户价值**：承接「silk scarf manufacturer」「custom silk scarf wholesale」等长尾搜索，低成本获客。
- **需求描述**：文章列表与详情，支持分类（面料知识 / 趋势报告 / 搭配指南 / 定制指南）、作者、发布时间、相关产品挂载。
- **验收标准**：
  - [ ] 每篇文章有唯一 title/description 与结构化数据（Article）。
  - [ ] 文章内可插入产品卡片，点击进入详情页。
  - [ ] 自动生成 sitemap 并包含全部文章。

### REQ-011：目录 PDF 下载（留资）（P1）

- **用户价值**：买家需要向老板/团队汇报，PDF 目录是刚需。
- **需求描述**：填写邮箱+公司名后获取当季 PDF 目录（≤15MB），同时进入邮件培育序列。
- **验收标准**：
  - [ ] 留资成功后可立即下载，链接 7 天内有效。
  - [ ] 未留资不可直接拿到 PDF 直链。

### REQ-012：询盘通知与 CRM 同步（P0，内部）

- **用户价值**：确保询盘不丢、可分配、可统计。
- **需求描述**：询盘写入统一存储，触发邮件通知（销售组）与 CRM Webhook；后台可按类型（询盘/样品/定制）、国家、状态筛选与导出。
- **验收标准**：
  - [ ] 任一渠道提交的询盘均可在后台查到，含来源页面与 UTM。
  - [ ] 通知失败时重试 3 次并记录告警，询盘数据不丢。
  - [ ] 导出 CSV 字段与表单字段一致。

### REQ-013：案例与客户评价（P1）

- **用户价值**：同类客户背书降低决策成本。
- **需求描述**：案例卡（客户类型、市场、定制内容、交付量、周期），客户 logo 墙（须有授权），评价引用。
- **验收标准**：
  - [ ] 每个案例标注可公开范围，未授权客户以「European boutique brand」等匿名形式呈现。
  - [ ] 案例可关联到具体产品/系列。

### REQ-014：法务与合规（P0）

- **用户价值**：欧美买家与广告投放的合规前提。
- **需求描述**：Cookie 同意横幅（分类同意：必要/统计/营销）、隐私政策、服务条款、出口合规声明、图片与花型版权声明。
- **验收标准**：
  - [ ] 未同意统计类 Cookie 前，GA4 等脚本不加载。
  - [ ] 页脚可访问隐私政策与条款，且支持后续修订版本号。
  - [ ] 表单收集邮箱处有用途说明与退订方式。

### REQ-015：数据埋点与转化分析（P0）

- **用户价值**：判断哪些款、哪些渠道真正带来询盘。
- **需求描述**：接入 GA4（或等效），埋点事件见《关键流程与验收标准》。
- **验收标准**：
  - [ ] 关键事件（view_item / click_cta_quote / submit_inquiry / submit_sample / download_catalog / whatsapp_click）在 GA4 实时报告中可见。
  - [ ] 询盘记录携带 UTM 与来源页面，可与 GA4 归因对照。

## 4. 产品规则

### 4.1 页面与交互

| 位置 / 入口 | 用户操作 | 系统反馈 | 备注 |
|---|---|---|---|
| 全局导航 | 点击 Collection / Customization / Factory / About / Contact | 跳转对应页；移动端为抽屉菜单 | 导航项 ≤ 6，避免层级过深 |
| 产品卡片 | Hover（桌面）/ 点击 | Hover 展示第二张图；点击进入详情 | 移动端不做 hover 依赖 |
| 产品详情页 | 点击 Get a Quote | 打开询盘表单，自动带入款号、名称、图片缩略 | 表单为侧滑面板或独立页，移动端全屏 |
| 产品详情页 | 点击 Request Sample | 打开样品表单，带入款号 | 与询盘共用组件，类型不同 |
| 询盘表单 | 提交 | 成功页展示询盘编号 + 回复承诺 | 不跳转首页 |
| 全站 | 点击 WhatsApp | 唤起 wa.me 深链，预填产品款号 | 桌面打开新标签 |
| 页脚 | 切换语言/币种 | 刷新当前页对应语言/币种 | 保留路径 |

### 4.2 字段与校验

**询盘 / 样品表单字段**

| 字段 | 类型 | 是否必填 | 默认值 | 校验规则 | 展示 / 使用位置 |
|---|---|---|---|---|---|
| Full Name | 文本 | 是 | — | 2–60 字符 | 询盘、样品 |
| Company | 文本 | 是 | — | 2–80 字符 | 询盘、样品 |
| Business Email | 邮箱 | 是 | — | 标准邮箱格式；拒绝一次性邮箱域名 | 询盘、样品 |
| Country / Region | 下拉（含搜索） | 是 | — | 国家清单 | 询盘、样品 |
| WhatsApp / Phone | 文本 | 否 | — | 含国际区号，8–20 位 | 询盘、样品 |
| Inquiry Type | 单选 | 是 | Quotation | Quotation / Customization / Sample / Other | 询盘、样品 |
| Product Ref | 文本 | 否 | 由页面带入 | 款号格式 `SC-XXXX` | 产品页带入 |
| Target Quantity | 数字 | 是 | — | 1–1,000,000 整数 | 询盘、样品 |
| Customization Needs | 多选 | 否 | 空 | 花型 / 配色 / 尺寸 / logo / 包装 / 洗标 | 询盘、定制 |
| Target Market | 文本 | 否 | — | ≤80 字符 | 询盘 |
| Message | 多行文本 | 是 | — | 10–2000 字符 | 询盘、样品 |
| Reference Files | 文件 | 否 | — | ≤3 个，单文件 ≤10MB，jpg/png/pdf | 询盘、定制 |
| Consent | 勾选 | 是 | 未勾选 | 必须勾选隐私政策同意 | 询盘、样品 |

**样品专属字段**

| 字段 | 类型 | 是否必填 | 校验规则 |
|---|---|---|---|
| Shipping Address | 多行文本 | 是 | 10–300 字符 |
| City / Postal Code | 文本 | 是 | ≤40 字符 |
| Courier Account | 文本 | 否 | ≤40 字符（到付账号） |

### 4.3 状态与流转

| 操作 | 前置状态 | 目标状态 | 用户可见反馈 |
|---|---|---|---|
| 提交询盘 | 表单已填 | 提交中 → 成功 | 按钮 loading，成功后展示编号页 |
| 提交失败 | 提交中 | 失败 | 顶部错误提示 + 保留输入 + 重试按钮 |
| 触发限流 | — | 拒绝 | 「提交过于频繁，请 10 分钟后再试或直接邮件联系」 |
| 上传附件 | — | 上传中 → 完成 | 进度条 + 可删除 |
| 附件超限 | — | 拒绝 | 明确提示大小/数量限制，不阻断其他字段 |

**询盘内部状态**：`new → assigned → quoted → sampling → won / lost`（P0 仅需 `new` 可查，其余 P1）

## 5. 约束与风险

### 5.1 非功能要求

| 类别 | 要求 | 验收方法 |
|---|---|---|
| 性能 | 移动端 LCP ≤ 2.5s、CLS < 0.1、INP < 200ms（4G） | Lighthouse / PageSpeed Insights |
| 图片 | WebP/AVIF + 响应式 srcset；单图首屏 ≤ 200KB | 构建产物检查 |
| SEO | 每页唯一 title/description；Product / BreadcrumbList / Organization 结构化数据；sitemap + robots；hreflang | Rich Results Test、Search Console |
| 可访问性 | WCAG 2.1 AA：对比度、键盘可达、表单 label 关联、图片 alt | axe 扫描 + 人工抽检 |
| 安全 | 表单防垃圾（honeypot + 限流）、附件类型校验、无明文密钥 | 渗透自检清单 |
| 可用性 | 静态资源 CDN，可用性 ≥ 99.9% | 监控告警 |
| 可观测 | 表单提交成功率、API 错误率、询盘到达延迟 | 监控看板 |
| 兼容 | 最近 2 个大版本的 Chrome / Safari / Edge / iOS Safari / Android Chrome | 真机抽检 |

### 5.2 风险与待确认

| 类型 | 描述 | 影响 | 处理方式 |
|---|---|---|---|
| 风险 | 产品图/证书/案例素材不足，导致页面「空壳化」 | 转化率与信任度直接受损 | 上线前设素材就绪门槛（见里程碑 M1） |
| 风险 | 阶梯价公开可能被同行比价、被老客质疑 | 商务被动 | 展示区间价 + 明确「最终以正式报价单为准」；敏感款可隐藏价格改为「Contact for price」 |
| 风险 | 询盘量大但质量低，销售跟进不过来 | 人力成本上升 | 必填数量+用途；设最低 MOQ 提示；后台按国家/数量分级 |
| 风险 | 阿语 RTL 与多语言内容维护成本高 | 上线延期 | P1 分批上线，先 EN/ES |
| 待确认 | 真实月产能、员工数、出口国别数 | 信任页数字文案 | 由卖家提供并确认可公开口径 |
| 待确认 | 认证清单与有效期（OEKO-TEX / BSCI / Sedex / ISO） | 认证墙内容 | 卖家提供证书扫描件 |
| 待确认 | 打样费、样品费、运费承担与抵扣规则 | 样品政策文案 | 卖家确认商务政策 |
| 待确认 | 阶梯价档位与 MOQ 是否按款差异 | 产品详情页价格模块 | 按品类给出 2–3 套模板，逐个 SKU 配置 |
| 待确认 | 收款与贸易条款（FOB / EXW / CIF） | 报价口径说明 | 统一默认 FOB，特殊款单独标注 |
