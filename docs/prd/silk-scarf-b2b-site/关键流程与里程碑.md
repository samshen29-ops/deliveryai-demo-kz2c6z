# 关键流程、埋点与里程碑

> 配套文档：《PRD.md》《信息架构与页面清单.md》。

## 1. 关键用户流程

### 1.1 询盘（Quotation）主流程

```
落地页 / 产品详情
   │  点击 Get a Quote
   ▼
询盘面板（款号、名称自动带入）
   │  填写：姓名 / 公司 / 邮箱 / 国家 / 类型 / 目标数量 / 需求描述 / 同意隐私政策
   ▼
前端校验 → POST /api/inquiries（幂等键：邮箱+款号+10 分钟窗口）
   ▼
成功页：询盘编号 + 24h 回复承诺 + 推荐相关款 + WhatsApp
   │
   ├─ 销售邮件通知（≤1 分钟）
   └─ CRM 建单（≤1 分钟），失败重试 3 次并告警
```

**异常分支**
- 校验失败：字段级提示，不清空已填内容。
- 网络失败：顶部错误条 + 重试按钮 + 已填内容保留（localStorage 暂存 30 分钟）。
- 限流（同 IP 10 分钟 > 5 次）：友好提示 + 邮箱兜底。
- 附件超限：仅该附件报错，其余字段可继续提交。

### 1.2 样品（Sample）主流程

```
产品详情 → Request Sample
   ▼
样品表单（收件信息 + 数量 + 是否接受样品费/运费到付）
   ▼
提交前展示样品政策（样品费、运费、抵扣规则）
   ▼
成功页：样品单号 + 预计寄出时间
```

### 1.3 定制（OEM/ODM）流程

```
Customization 页 → Start Your Custom Project
   ▼
带定制上下文的询盘（类型=Customization，多选定制维度）
   ▼
销售对接 → 打样 → 样品确认 → 大货
```

## 2. 埋点事件

| 事件名 | 触发时机 | 关键参数 |
|---|---|---|
| `view_home` | 首页曝光 | lang, utm_* |
| `view_collection` | 列表页曝光 | series, filters |
| `apply_filter` | 应用筛选 | filter_key, filter_value, result_count |
| `view_item` | 详情页曝光 | item_ref, series, price_range |
| `click_cta_quote` | 点击 Get a Quote | item_ref, page_type, position |
| `click_cta_sample` | 点击 Request Sample | item_ref, page_type |
| `begin_inquiry` | 表单首次输入 | inquiry_type |
| `submit_inquiry` | 询盘提交成功 | inquiry_type, country, target_qty, has_files |
| `submit_sample` | 样品提交成功 | country, sample_qty |
| `inquiry_failed` | 提交失败 | reason（validation / network / rate_limit） |
| `download_catalog` | 目录留资下载 | lang |
| `whatsapp_click` | 点击 WhatsApp | page_type, item_ref |
| `switch_language` | 切换语言 | from, to |
| `switch_currency` | 切换币种 | from, to |

**转化漏斗定义**：`view_item → click_cta_quote → begin_inquiry → submit_inquiry`，按 series / 国家 / 语言拆维度。

## 4. 里程碑与准入门槛

| 里程碑 | 交付物 | 准入门槛 |
|---|---|---|
| M1 内容就绪 | 产品素材包、认证件、产能数据、文案、域名与邮箱 | 每个 P0 SKU 有 ≥6 张图 + 完整规格；≥3 项认证可公开；域名邮箱可用 |
| M2 P0 上线 | 站点部署、表单打通、埋点验证、法务页 | P0 验收清单全绿；移动端 Lighthouse 性能 ≥85；询盘端到端测试通过 |
| M3 增长 | 多语言、内容、目录下载、案例 | P1 需求上线；Search Console 收录率 ≥90%；询盘量基线建立 |

**M1 素材清单（需卖家提供）**

1. 当季主推 20–30 款的产品图（整幅 / 微距 / 卷边 / 色卡 / 场景 / 包装）
2. 材质与工艺参数（成分、克重、尺寸、卷边方式）
3. MOQ、阶梯价档位、打样费、样品费与运费政策
4. 认证证书扫描件（含有效期）与验厂报告摘要
5. 工厂实景照片与视频、设备清单、月产能、员工数、出口国别
6. 可公开的客户案例与授权 logo
7. 域名、企业邮箱、WhatsApp Business 号码
8. 隐私政策与服务条款的法务确认稿

## 5. 交付可行性初判（按《需求打标规范》）

| 维度 | 初判 | 理由 |
|---|---|---|
| scope | WARN | 新建整站，涉及页面、组件、数据与表单接口，文件量超出 15 个 |
| interface | WARN | 询盘/产品接口为新建契约，需先定字段与幂等规则 |
| pattern | PASS | 仓库已有 React + Vite + Tailwind + i18n + Playwright 范式可复用 |
| testability | PASS | 页面结构、表单校验、提交结果、埋点均可客观断言 |
| dependency | WARN | 需域名、企业邮箱、CRM/Webhook、GA4、对象存储等外部配置 |
| safety | PASS | 无支付、无隐私写入到第三方核心系统以外的不可逆操作 |
| closure | PASS | 单仓闭环（Demo 仓内新建站点目录） |

**结论：B 类（AI 辅助编程）**。建议按「首页 + 目录/详情 → 表单与通知 → 合规与埋点 → 多语言」四批拆分推进，接口契约与外部依赖（M1 素材与账号）先行确认。

## 6. 上线验收脚本（人工 + 自动化）

1. 移动端 4G 打开首页，首屏 3 秒内可见主 CTA。
2. 从首页进入任一产品详情，点击 Get a Quote，款号自动带入。
3. 故意漏填「目标数量」，应阻止提交并高亮该字段。
4. 完整填写并提交，记录询盘编号；检查销售邮箱与 CRM 均在 1 分钟内收到。
5. 同 IP 连续提交 6 次，第 6 次应被限流并给出邮箱兜底提示。
6. 提交样品申请，确认样品政策在提交前可见。
7. 拒绝统计类 Cookie 后，确认 GA4 未加载；同意后事件可上报。
8. 切换语言后当前页面路径保留，hreflang 正确。
9. axe 扫描无严重（critical）可访问性问题。
10. 检查认证图片可打开、有效期为未来日期。
